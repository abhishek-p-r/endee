QUICK START INSTRUCTIONS
================================================================================

METHOD 1: Docker Compose (Fastest - 5 minutes)

1. Get OpenAI API key from https://platform.openai.com/api-keys
2. Clone repository:
   git clone https://github.com/abhishek-p-r/endee.git
   cd endee

3. Configure environment:
   cp .env.example .env
   nano .env  # Add your OPENAI_API_KEY

4. Start everything:
   docker-compose up -d

5. Open browser:
   http://localhost:8501

6. Upload a document and ask questions!

METHOD 2: Manual Setup (3 Terminals)

Terminal 1: Endee Database
   docker run -p 8001:8001 endeeio/endee:latest

Terminal 2: Backend API
   source venv/bin/activate
   python -m uvicorn backend.app:app --port 8000

Terminal 3: Frontend
   source venv/bin/activate
   streamlit run frontend/app.py --port 8501

Then open: http://localhost:8501

TROUBLESHOOTING
================================================================================

Issue: Can't connect to Endee
→ Check: docker-compose ps
→ Fix: docker-compose up endee-db -d

Issue: API key invalid
→ Check: echo $OPENAI_API_KEY
→ Fix: Get key from platform.openai.com, update .env

Issue: Port in use
→ Check: lsof -i :8501
→ Fix: Kill process or use different port

Issue: No search results
→ Check: Upload more documents first
→ Fix: Try different search terms

More issues? Check: docs/TROUBLESHOOTING.md
