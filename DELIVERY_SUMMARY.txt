HOW TO RUN
================================================================================

OPTION 1: DOCKER COMPOSE (EASIEST - 5 MINUTES)
────────────────────────────────────────────────

1. Prepare:
   cp .env.example .env
   # Edit .env and add: OPENAI_API_KEY=sk-your-key

2. Start:
   docker-compose -f docker-compose-app.yml up

3. Access:
   - Frontend: http://localhost:8501
   - API: http://localhost:8000/docs
   - Endee: http://localhost:6379

OPTION 2: MANUAL SETUP (10 MINUTES)
────────────────────────────────────

Terminal 1 - Backend:
  cd backend_v2
  python main.py

Terminal 2 - Frontend:
  cd frontend_v2
  streamlit run app.py

Then access http://localhost:8501

OPTION 3: STEP-BY-STEP GUIDE
──────────────────────────────

Follow STARTUP_GUIDE.md for detailed instructions including:
- Prerequisites
- Environment setup
- Endee server configuration
- Document ingestion
- System testing

CONFIGURATION OPTIONS
================================================================================

REQUIRED:
• OPENAI_API_KEY - Your OpenAI API key (from https://platform.openai.com/api-keys)

RECOMMENDED DEFAULTS (all configured):
• ENDEE_URL=http://localhost:6379
• OPENAI_MODEL=gpt-3.5-turbo
• CHUNK_SIZE=512
• CHUNK_OVERLAP=50
• RAG_TOP_K=5

OPTIONAL TWEAKS:
• RAG_TEMPERATURE - Model creativity (0-1, default 0.7)
• RAG_MAX_TOKENS - Answer length limit (default 1000)
• PORT - Server port (default 8000)

See .env.example for all options.
