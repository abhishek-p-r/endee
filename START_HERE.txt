                    ENDEE RAG SYSTEM - START HERE
================================================================================

Welcome to the Endee RAG (Retrieval-Augmented Generation) System!

This is a complete, production-ready AI application that combines:
- Endee Vector Database (semantic search)
- OpenAI GPT-4o-mini (answer generation)
- Streamlit (web interface)
- FastAPI (REST API)

================================================================================
                              QUICK START (5 MIN)
================================================================================

1. SET UP ENVIRONMENT
   export OPENAI_API_KEY="sk-your-api-key-here"

2. START ENDEE DATABASE
   docker run -p 8000:8000 endeeio/endee:latest

3. START BACKEND API (NEW TERMINAL)
   python -m uvicorn backend.app:app --host 0.0.0.0 --port 8000

4. START WEB UI (NEW TERMINAL)
   streamlit run frontend/app.py

5. OPEN BROWSER
   http://localhost:8501

================================================================================
                           SYSTEM COMPONENTS
================================================================================

WHAT EACH COMPONENT DOES:

1. ENDEE VECTOR DATABASE (backend/endee_vector_db.py)
   - Stores document embeddings as vectors
   - Performs semantic similarity search
   - Retrieves relevant documents for queries

2. OPENAI INTEGRATION (backend/openai_client.py)
   - Converts documents to embeddings (text-embedding-3-small)
   - Generates answers from context (GPT-4o-mini)
   - Provides streaming responses

3. DOCUMENT PROCESSOR (backend/document_processor.py)
   - Loads .txt, .pdf, .md files
   - Splits text into chunks
   - Cleans and normalizes text

4. RAG PIPELINE (backend/rag_system.py)
   - Orchestrates the complete workflow:
     1. Generate embedding from user query
     2. Search Endee for similar documents
     3. Retrieve top matching chunks
     4. Generate answer using OpenAI
     5. Return answer with sources

5. FASTAPI BACKEND (backend/app.py)
   - REST API with 9 endpoints
   - Document upload and ingestion
   - Semantic search
   - Answer generation with streaming
   - Query optimization

6. STREAMLIT WEB UI (frontend/app.py)
   - Chat interface for questions
   - Document upload interface
   - Semantic search exploration
   - Analytics dashboard
   - System configuration panel

================================================================================
                         TYPICAL WORKFLOW
================================================================================

USER QUERY
    ↓
[UPLOAD DOCUMENTS] (Streamlit UI or REST API)
    ↓
[PROCESS & CHUNK] (Split into manageable pieces)
    ↓
[GENERATE EMBEDDINGS] (Convert to vectors with OpenAI)
    ↓
[STORE IN ENDEE] (Save vectors in database)
    ↓
[USER ASKS QUESTION]
    ↓
[GENERATE QUERY EMBEDDING] (Convert question to vector)
    ↓
[SEMANTIC SEARCH] (Find similar documents in Endee)
    ↓
[RETRIEVE CONTEXT] (Get top matching chunks)
    ↓
[GENERATE ANSWER] (Use OpenAI GPT-4o-mini)
    ↓
[STREAM RESPONSE] (Return answer + sources to user)
    ↓
[DISPLAY IN WEB UI]

================================================================================
                      GETTING STARTED CHECKLIST
================================================================================

PRE-SETUP:
□ Python 3.9+ installed
□ Docker installed
□ OpenAI API key obtained (https://platform.openai.com/api-keys)
□ Endee code cloned or downloaded

INSTALLATION:
□ Run: python scripts/verify_setup.py (to check requirements)
□ Run: pip install -r requirements.txt (install dependencies)
□ Run: cp .env.example .env (create config file)
□ Edit .env with your OPENAI_API_KEY

STARTUP:
□ Terminal 1: docker run -p 8000:8000 endeeio/endee:latest
□ Terminal 2: python -m uvicorn backend.app:app --host 0.0.0.0 --port 8000
□ Terminal 3: streamlit run frontend/app.py
□ Open: http://localhost:8501

FIRST TEST:
□ Run: python scripts/demo.py (interactive demo)
□ Upload a document via web UI
□ Ask a question
□ See the answer with sources

UPLOAD DOCUMENTS:

  Web UI: Chat tab → Type question → Send
  API:    curl -X POST http://localhost:8000/ask -H "Content-Type: application/json" \
          -d '{"question":"Your question here"}'

SEARCH DOCUMENTS:
  Web UI: Search tab → Enter search query → Search
  API:    curl -X POST http://localhost:8000/search -H "Content-Type: application/json" \
          -d '{"question":"search term"}'

STREAM ANSWER:
  API:    curl -X POST http://localhost:8000/stream -H "Content-Type: application/json" \
          -d '{"question":"Your question"}' --no-buffer

VIEW API DOCS:
  http://localhost:8000/docs (Swagger UI)
  http://localhost:8000/redoc (ReDoc)
