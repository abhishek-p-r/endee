SYSTEM OVERVIEW
================================================================================

What It Does:
  1. Loads documents (.txt, .pdf, .md)
  2. Splits into intelligent chunks (512 characters)
  3. Converts to 1536-dimensional embeddings (OpenAI)
  4. Stores in Endee vector database
  5. On query: searches Endee, retrieves context, generates GPT answer

Key Components:
  • Endee Vector DB (port 6379) - Vector storage & semantic search
  • FastAPI Backend (port 8000) - REST API with 8+ endpoints
  • Streamlit UI (port 8501) - Interactive web interface
  • OpenAI API - Embeddings (text-embedding-3-small) & GPT-3.5-turbo

INSTALLATION (5 MINUTES)
================================================================================

Prerequisites:
  - Python 3.10+ OR Docker
  - OpenAI API Key (https://platform.openai.com/api-keys)
  - 4GB RAM minimum

Steps:
  1. git clone https://github.com/abhishek-p-r/endee.git
  2. cd endee
  3. cp .env.example .env
  4. Get OpenAI key: https://platform.openai.com/api-keys
  5. Edit .env: OPENAI_API_KEY=sk-your-key-here

HOW ENDEE VECTOR DATABASE IS USED
================================================================================

1. DOCUMENT INGESTION:
   .txt/.pdf/.md → Split into chunks (512 chars, 50 char overlap)
                → Generate embeddings (1536 dimensions, OpenAI)
                → Store in Endee with metadata
                   • document_id, chunk_id, source
                   • text, chunk_index, timestamps
                   • custom metadata

2. VECTOR STORAGE IN ENDEE:
   Collection: "knowledge_base"
   - Metric: cosine similarity
   - Dimension: 1536 (text-embedding-3-small)
   - Metadata: Rich document metadata included

3. SEMANTIC SEARCH:
   User query → Generate embedding (1536 dims, OpenAI)
            → Endee similarity search
            → Retrieve top-5 chunks with scores (0-1)
            → Filter by threshold (0.5 default)

4. CONTEXT RETRIEVAL:
   Retrieved chunks → Extract text & metadata
                   → Format with sources
                   → Pass to GPT with query

5. ANSWER GENERATION:
   Query + Context → GPT-3.5-turbo
                  → Generate answer
                  → Return with sources

6. RESPONSE BACK TO USER:
   {
     "answer": "Endee is a vector database...",
     "sources": ["doc1.pdf", "doc2.txt"],
     "retrieval_time": 0.234s,
     "generation_time": 2.156s
   }

TROUBLESHOOTING
================================================================================

Problem: "Connection refused" at localhost:6379
Solution: 1. Make sure Endee is running
          2. curl http://localhost:6379/health
          3. If not running: docker run -p 6379:6379 endeeio/endee:latest

Problem: "Invalid API key" for OpenAI
Solution: 1. Get key from: https://platform.openai.com/api-keys
          2. Key must start with "sk-"
          3. Add to .env: OPENAI_API_KEY=sk-your-key
          4. Restart backend

Problem: "No documents found" in search
Solution: 1. Check data/ folder has .txt/.pdf/.md files
          2. Run: cd backend_v2 && python ingest_documents.py
          3. Check stats: curl http://localhost:8000/stats
          4. Restart backend

Problem: "Port already in use"
Solution: Kill existing process or change port:
          python -m backend_v2.main --port 8001
          streamlit run frontend_v2/app.py --server.port 8502

Problem: "Slow responses" (>10 seconds)
Solution: 1. Reduce RAG_TOP_K from 5 to 3 in .env
          2. Check API rate limits
          3. Verify network connection
          4. Monitor logs for errors
