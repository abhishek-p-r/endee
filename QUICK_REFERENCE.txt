================================================================================
SYSTEM OVERVIEW
================================================================================

What It Does:
  1. Loads .txt documents
  2. Converts to 384-dimensional embeddings
  3. Stores in Endee vector database
  4. Retrieves relevant documents on query
  5. Uses Gemini AI to generate answers

Key Components:
  • Endee Vector Database (localhost:8080) - Vector storage & search
  • FastAPI Backend (localhost:8000) - API server
  • Streamlit UI (localhost:8501) - Web interface
  • Python Processing - Embeddings, orchestration, AI

================================================================================
INSTALLATION (5 minutes)
================================================================================

Prerequisites:
  - Python 3.8+
  - Git
  - 4GB RAM

Steps:
  1. git clone https://github.com/abhishek-p-r/endee.git
  2. cd endee && git checkout endee-ai-assistant
  3. python -m venv venv && source venv/bin/activate
  4. pip install -r requirements.txt
  5. cp .env.example .env
  6. Get Gemini API key: https://makersuite.google.com/app/apikey
  7. Add to .env: GEMINI_API_KEY=your_key

================================================================================

METHOD 1: AUTOMATED (Fastest - 5 minutes)

================================================================================
HOW ENDEE IS USED
================================================================================

1. DOCUMENT INGESTION:
   .txt file → Split into chunks (500 chars, 200 char overlap)
             → Generate embeddings (384 dimensions)
             → Upsert to Endee with metadata

2. SEMANTIC SEARCH:
   User question → Generate embedding (same model as documents)
                → Endee search (cosine similarity)
                → Retrieve top-5 results

3. ANSWER GENERATION:
   Retrieved docs → Build context
                 → Send to Gemini AI
                 → Generate answer
                 → Add source citations

4. RESPONSE:
   Answer + Sources → Return to user

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Connection to Endee failed"
Solution: 1. curl http://localhost:8080/health
          2. If fails, start: cd endee && ./run.sh
          3. Check .env ENDEE_URL

Problem: "GEMINI_API_KEY not found"
Solution: 1. Get from: https://makersuite.google.com/app/apikey
          2. Add to .env file
          3. Restart backend

Problem: "No documents found"
Solution: 1. Add .txt files to data/
          2. Run: python scripts/ingest_documents.py
          3. Restart backend

Problem: "Port already in use"
Solution: Change port in command:
          python -m uvicorn backend.main:app --port 8001
          streamlit run frontend/streamlit_app.py --server.port 8502
