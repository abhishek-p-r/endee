YOUR FIRST 5 MINUTES
================================================================================

STEP 1: Get OpenAI API Key (1 minute)
   1. Go to: https://platform.openai.com/api-keys
   2. Click "Create new secret key"
   3. Copy the key (starts with sk-)

STEP 2: Clone & Configure (1 minute)
   git clone https://github.com/abhishek-p-r/endee.git
   cd endee
   cp .env.example .env
   nano .env  # Add your OPENAI_API_KEY

STEP 3: Run Everything (1 minute)
   docker-compose up -d
   sleep 30  # Wait for services to start

STEP 4: Open Browser (1 minute)
   http://localhost:8501

STEP 5: Test It (1 minute)
   • Upload a PDF or TXT file
   • Ask a question
   • See the AI answer!

DONE! 🎉

For more details, see QUICK_START.md
